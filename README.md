# PAC-MAN · Neon Run

모바일과 웹에서 플레이하는 조이스틱 중심 미로 아케이드입니다. 별도 설치나 외부 라이브러리 없이 `index.html`로 실행합니다.

## 조작
- 모바일: 원형 조이스틱을 원하는 방향으로 밀기
- PC: 조이스틱 마우스 드래그 또는 방향키 / WASD
- 이동 중 모퉁이 방향 예약 가능. 조이스틱을 놓아도 진행 방향으로 이동합니다.
- 상단 버튼: 음악·효과음 켜기/끄기, 일시정지. 직접 만든 4마디 칩튠 배경음악(멜로디·베이스·아르페지오·드럼)이 게임 시작부터 반복되며, 파워 펠렛을 먹으면 템포와 음역이 올라갑니다. 음소거 설정은 기기에 저장합니다. 다른 앱으로 전환하거나 창 포커스를 잃으면 자동 일시정지합니다.

## 게임 규칙
도트 10점, 파워 펠렛 50점. 파워 상태에서는 유령 연속 먹기 200 / 400 / 800 / 1600점. 보너스 과일은 300 × 스테이지 점수입니다. 목숨 3개, 도트를 모두 먹으면 다음 스테이지로 진행합니다. 다음 스테이지는 원본 미로를 좌우 반전해 번갈아 사용하며 속도가 점차 증가합니다. 최고 점수는 브라우저에 저장합니다.

유령 4종: 직접 추격, 전방 차단, 측면 접근, 근거리 회피. 파워 상태에서는 유령이 모퉁이로 도망가며, 먹힌 유령은 집으로 돌아옵니다.

## 실행 및 확인
`python3 -m http.server 8765`를 이 폴더에서 실행한 후 `http://localhost:8765` 접속.
`node --test tests/game.test.cjs`로 미로 도달성 및 핵심 게임 규칙을 검사합니다.

원본 프로토타입은 `reference/prototype.html`에 보관했습니다. 조이스틱의 원형 링, 노브, 포인터 캡처 방식은 기존 MagicCastleEscape 구현을 참조했습니다.

GitHub Pages를 사용하려면 저장소 Settings → Pages에서 main 브랜치의 /(root)를 선택하세요. 배포 설정은 자동 변경하지 않습니다.
